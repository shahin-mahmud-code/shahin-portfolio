# shahin-portfolio

Personal portfolio website for Shahin Mahmud, built with [Astro](https://astro.build) and TypeScript.

Live site: https://shahin-mahmud-code.github.io/shahin-portfolio/

## Develop

Requires Node 22.23.4 or newer (26 LTS recommended).

```sh
npm install
npm run dev      # http://localhost:4321/shahin-portfolio/
npm run check    # type-check
npm run build    # output in dist/
npm run preview  # serve the production build
```

## Deploy

Pushes to `main` are built and published to GitHub Pages by `.github/workflows/deploy.yml`.
In the repository settings, set Pages > Source to "GitHub Actions".
